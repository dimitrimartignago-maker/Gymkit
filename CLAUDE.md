# GymKit - Contesto Progetto

## Stack Tecnico
- **Frontend**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Backend**: Supabase (Database & Auth)
- **Package Manager**: npm

## Convenzioni di Sviluppo
- Componenti in `src/components` (usare PascalCase)
- Pagine in `src/app`[cite: 1]
- Tipi in `src/types`[cite: 1]
- Mantieni il codice semplice: app per singolo trainer[cite: 1]

## Comandi Rapidi
- Sviluppo: npm run dev[cite: 1]
- Build: npm run build[cite: 1]
